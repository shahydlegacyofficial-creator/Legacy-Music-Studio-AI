# Legacy Music Studio AI — acquisition listing kit

## Tagline

Private, local AI music generation for musicians and creators.

## Short description

Legacy Music Studio AI is a polished Windows music-generation platform that
transforms lyrics and creative direction into vocal and instrumental tracks
using MiniMax Music 3 on the user's own NVIDIA GPU.

## Full description

Legacy Music Studio AI is a local-first AI music creation platform built for
musicians, producers, filmmakers, game developers and content creators.

Users enter original lyrics and describe the genre, mood, vocals and
arrangement, then generate music through a professional interface without
uploading their projects to a third-party music platform or paying per-track API
fees.

The application hides the complexity of ComfyUI and MiniMax Music 3 behind an
accessible Windows dashboard. It includes 20 curated genre systems, intelligent
GPU detection, repeatable generation seeds, lossless FLAC export, a local music
library and a Remix workflow.

The product is a working, bootstrapped MVP with a downloadable Windows
application and hosted companion dashboard. It can be monetized through desktop
licenses, creator packages, studio licenses or expanded into a cloud-generation
subscription service.

## Value proposition

Legacy Music Studio AI gives creators a private alternative to cloud-only AI
music platforms. Projects and lyrics remain on the creator's computer, while
local GPU generation removes recurring per-track API costs.

## Problem solved

Running open-weight music models locally is technically difficult. Legacy Music
Studio AI packages the setup, runtime, prompt structure, hardware protection and
track management into a creator-friendly product.
